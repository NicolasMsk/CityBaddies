## 3️⃣ INDEXATION & CRAWL BUDGET

### robots.txt

```
User-agent: *
Allow: /
Allow: /_next/image
Disallow: /api/
Disallow: /admin/
Disallow: /auth/
Disallow: /profile/
Disallow: /_next/static/
Disallow: /deals?*         ← ATTENTION
```

### ⚠️ PROBLÈME DÉTECTÉ

**Le `Disallow: /deals?*` bloque TOUTES les URLs avec query params**, y compris :
- `/deals?page=2` (pages paginées) ❌
- `/deals?category=...` (filtres) ← OK à bloquer
- `/deals?brand=...` (filtres) ← OK à bloquer

**Impact :** Les pages paginées `/deals?page=N` sont dans le sitemap mais bloquées par robots.txt !

### 🔧 Correction recommandée

```typescript
// robots.ts - Version corrigée
disallow: [
  '/api/',
  '/admin/',
  '/auth/',
  '/profile/',
  '/deals?category=*',  // Bloquer les filtres catégorie
  '/deals?merchant=*',  // Bloquer les filtres marchand
  '/deals?brand=*',     // Bloquer les filtres marque
  '/deals?search=*',    // Bloquer la recherche
  // NE PAS bloquer /deals?page=*
],
```
