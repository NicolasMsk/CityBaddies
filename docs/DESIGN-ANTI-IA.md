# Référentiel anti-« design IA » — City Baddies

> Compilé le 13 juillet 2026 (recherche : Developers Digest, Impeccable.style, Publishd,
> 925 Studios, NN/g, HN, analyses logos IA, rapport UW sur l'homogénéisation du vibe-coding).
> À consulter avant TOUT choix visuel/copy sur le site.

## Les 3 « looks IA » reconnaissables en 2026
1. Crème #F4F1EA + serif contrasté + accent terracotta (le « look Claude », documenté New Yorker)
2. **Fond quasi-noir + un accent vif unique (or/néon) + glow** ← le look actuel de City Baddies
3. Broadsheet : hairlines, radius 0, colonnes denses façon journal

Aucun n'est interdit — mais il faut le rendre **spécifique** (texture, typo réelle, données) ou le tell reste.

## Marqueurs IA par dimension (et antidotes)

### Couleurs
- ✗ Gradients violet/indigo/cyan (le n°1), « VibeCode Purple », gradient text, glows néon diffus, gris « esthétique » à contraste limite
- ✓ Palette motivée par la marque, couleur sémantique, texte en couleur pleine, contraste ≥4.5:1

### Typographie
- ✗ Inter/Space Grotesk/Instrument Serif/Geist par défaut ; polices système jamais stylées ; **le mot en serif italique au milieu d'un titre sans** (cliché signature 2025-26) ; eyebrows ALL-CAPS partout ; hiérarchie plate
- ✓ Display avec personnalité + body sobre ; **mono pour les chiffres/prix** (assumé comme système) ; ratio ≥1.25 entre paliers ; caps réservées aux labels courts

### Layout
- ✗ Hero centré badge+H1+2 CTA ; 3 feature-cards symétriques avec icône ; stats « gros chiffre + petit label » ×3 ; sections 01/02/03 hors séquence ; radius uniforme ; espacement monotone ; glassmorphism
- ✓ Rythme cassé ≥2 fois (edge-to-edge, section courte, asymétrie 2+1) ; densité pilotée par le contenu ; un seul primitif de card

### Images/icônes
- ✗ **Photos de personnes générées par IA** (peau plastique, dents parfaites, bokeh doré) — le marqueur le plus fort ; blobs gradient ; ✨ sparkle ; Lucide générique au-dessus de chaque titre
- ✓ Vraies photos produits/screenshots/données ; hero typographique ; grain/texture ; icônes custom ou aucune

### Copy
- ✗ « Unlock/Elevate/Seamless », aphorismes (« Ce n'est pas X, c'est Y »), manifestos dramatiques, superlatifs creux (« ÉLITE »), tirets cadratins en série, triades, mélange tu/vous
- ✓ Verbe+nom concrets, chiffres réels, opinion assumée, vocabulaire de marque, ponctuation variée

### Confiance (spécifique comparateur)
- ✗ Prix sans horodatage ni source, méthodologie absente, monétisation opaque
- ✓ **« Relevé le 12/07 chez Sephora » sur chaque offre**, page méthodologie, disclosure affiliée, historique visible — la densité de données réelles est l'anti-slop le plus puissant

### Micro-craft
- ✓ ::selection à la marque, favicon dessiné, OG images par page, footer dense (mentions, contact, plan), motion fonctionnelle uniquement (ease-out, transform/opacity)

## Checklist 15 points (ordre d'impact)
1. Gradients violet/indigo → purger
2. Police par défaut → typo intentionnelle + mono chiffres
3. Grille 3 cards symétriques → asymétrie/éditorial
4. Headlines moyennées → concret+chiffres+opinion
5. Espacement/radius uniformes → varier, casser le rythme
6. Prix sans horodatage → provenance partout + méthodologie
7. ✨/Lucide générique/emoji nav → purger
8. Images IA/stock → réel ou typographique
9. Tirets cadratins/triades/aphorismes → réécrire
10. Glassmorphism/glow/gradient text → un seul langage d'élévation
11. Logo gradient générique → wordmark monochrome 16px
12. Pills au-dessus du H1, 01/02/03 hors séquence → supprimer
13. Footer maigre/légal creux → densifier
14. Animations décoratives uniformes → motion fonctionnelle
15. Micro-détails (selection, OG, texture) → soigner

**Méta-principe** : le tell = l'accumulation de défauts jamais questionnés. L'antidote = la spécificité (données réelles, vocabulaire propre, choix justifiables).
